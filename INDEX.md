# Workspace initialization resources

The workflow and completion criteria are maintained only in `SKILL.md`.

| Resource | Read when |
| --- | --- |
| `config.json` | Reusing or explicitly saving a project directory template |
| `resources/universal-rules.md` | Adding missing project defaults after checking inherited rules |
| `resources/powershell-guard.md` | Resolving a relevant PowerShell execution concern |
| `resources/clients.json` | Configuring an explicitly requested client integration |
| `resources/context7-mcp.json` | Configuring Context7 |
| `resources/project-memory-records/` | Installing project history support |
| `resources/github-commit/` | Installing commit and PR conventions |
| `resources/project-lingo/` | Installing project terminology support |
| `resources/project-index/` | Installing an optional module map |

Bundled helper entrypoints use `SKILL.md.template` until installation. Preserve existing installed helpers; updating this bundle does not migrate other projects automatically.
